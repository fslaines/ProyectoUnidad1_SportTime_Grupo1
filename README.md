# ProyectoUnidad1_SportTime_Grupo1

Sistema de Reservas de Canchas Deportivas (SportTime).
Proyecto de Unidad 1, Ingeniería de Software.

## Integrantes

- Julio Andrade
- Gerald Astudillo
- Francisco Laines
- Javier Olmos

## Caso asignado

**Grupo 1: SportTime.** Plataforma web/móvil para la gestión de complejos
deportivos: disponibilidad de canchas por hora, consulta de precios, reserva
en línea, pago, confirmación, consulta de reservas activas y cancelación de turnos.

Solicitud de cambio (Actividad 4): **Pago Compartido**.

## Estructura del repositorio

- `/frontend`: interfaz de usuario
- `/backend`: servicios y lógica del sistema
- `/docs`: documentación y diagrama de arquitectura (`/docs/architecture`)

## Instrucciones de ejecución

Abrir frontend/index.html en el navegador. No requiere instalación.
